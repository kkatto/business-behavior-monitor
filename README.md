# 业务流程透视监控系统
## 主要技术栈
SpringBoot、MyBatis、MySQL、Redis、Logback、OGNL 
## 项目描述
该项目专注于用户行为分析，透视系统过程中业务的流转。优化业务流程监控，实现实时质量跟踪、异常预警及精细化管理。项目采用基于扩展Logback日志上报数据进行OGNL配置节点公式的方式进行采集、计算和可视化渲染。
## 核心职责
1. 采用领域驱动设计(DDD)的分层架构，构建了高效、可维护的监控系统。独立开发并封装了基于扩展Logback的日志上报组件，实现了对业务系统的无侵入式数据采集。
2. 在监控中心模块中，主导了数据接收、解析与存储功能的开发工作。通过编写高效的数据处理逻辑，实现了对业务系统上报数据的实时、准确解析与入库，为后续的数据分析与可视化工作奠定了坚实基础。
